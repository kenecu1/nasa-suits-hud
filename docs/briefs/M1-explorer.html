Full state vs deltas

    
The backend sends the whole state each time. Here two clients watch the same stream: one gets full state, one gets only what changed. Turn up message loss and see which one drifts away from the truth.

  

  

    

      
      15%
      
    

    

    

  

  
With full state, a lost message costs at most one second of staleness, because the next one carries everything. With deltas, a lost change stays wrong until that field changes again. A late joiner never learns fields that don't change. The price of full state is size, and at a few KB once a second that is nothing.
